MANALI TOURISM WEBSITE
=======================

Pages:
1. index.html - Home
2. heritage.html - Heritage Sites
3. hotel.html - Hotel Booking
4. gallery.html - Gallery
5-16. Individual destination pages

Open index.html in a browser or use VS Code Live Server.

The site uses one shared style.css file and a consistent visual design.
Images are loaded from Unsplash URLs, so internet access is needed for photos.
The booking form is a front-end demonstration and does not process real reservations.
